# Roadmap

1. **Phase 1 — foundation (current):** monorepo, independent apps, local PostgreSQL schema isolation, info endpoints, frontend shell and architecture notes.
2. **Phase 2 — smallest useful planning slice:** Travel trip creation/editing, destinations and itinerary days; Property city comparison and monthly cost entries; explicit DTOs, ports, repositories and migrations; UI forms and meaningful tests.
3. **Later:** route alternatives, snapshots/imports, verified reference providers, optional local AI adapters, PDF export and hosted deployment.

Authentication, paid APIs and distributed infrastructure remain outside the plan until a specific need and approval arise.
