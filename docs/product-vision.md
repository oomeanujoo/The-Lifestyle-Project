# Product vision

The Lifestyle helps one user explore, compare, save and export major travel and housing decisions. Its first bounded contexts are Travel Planning and Property and Cost-of-Living Planning. AI can turn natural language into reviewable structured plans and explain options, while source-backed prices, visa details and user choices remain authoritative.

The first release path is local-first, free and open source. A later hosted deployment should replace local infrastructure through configuration and adapters without changing domain ownership. Phase 1 establishes runnable boundaries and a navigation shell; it does not promise live travel inventory or business planning screens.
